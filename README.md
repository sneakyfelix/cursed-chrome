**installation**

1. download this repository
   → either click “code” then “download zip” or clone it:
        git clone https://github.com/sneakyfelix/cursed-chrome.git
3. open chrome
   → chrome://extensions/
4. toggle on developer mode
5. click "load unpacked"
6. select cursed-chome folder
   → if successful, you’ll see the extension appear in your toolbar or in your extensions list
